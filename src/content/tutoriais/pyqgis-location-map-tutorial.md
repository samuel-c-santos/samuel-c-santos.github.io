## Sobre o projeto

Este tutorial mostra como automatizar a criação de mapas de localização no QGIS usando scripts Python (PyQGIS). O fluxo de trabalho gera mapas padronizados com três níveis de recorte geográfico: nacional (América do Sul), estadual (UF) e municipal.

## Conteúdo

- Configuração do ambiente PyQGIS
- Filtro dinâmico por município/estado
- Ajuste inteligente de escalas
- Variáveis de layout
- Exportação automatizada
